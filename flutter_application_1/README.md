# 🌸 Цветочный Тамагочи (Версия 1.0.0)

Мобильная игра на Flutter — уютный симулятор выращивания цветов.

## 🎮 О версии
Это **локальная версия** игры. Она работает полностью офлайн, без сервера. 
Все сохранения (монеты, цветок, достижения) хранятся на самом устройстве с помощью `shared_preferences`.

## 🚀 Как запустить
Игра находится в папке `flutter_application_1`. 
Для сборки APK перейдите в неё:
```bash
cd flutter_application_1
flutter pub get
flutter build apk --release
